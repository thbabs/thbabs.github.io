# thbabs.github.io

Portfolio site for Toluwase Babalola (Tolu), a data scientist and AI developer in Hull, UK.

GitHub Pages serves these static files from the root of `main` at <https://thbabs.github.io>. There is no build step.

## Preview locally

From the repository root:

```bash
python -m http.server
```

Open <http://127.0.0.1:8000>. Unknown paths are handled by `404.html` once the site is on GitHub Pages.

## Publish

After this is merged to `main`, enable Pages in the repository settings: **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.
